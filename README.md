# 轨迹回放

在同一个家庭维修场景中，对照 OS-native Agent 和 MobileClaw 处理六项持续委托的过程。选择任务或时间线事件，逐步查看手机画面、工具调用、关键参数、返回结果与已记录的推理。两侧可以独立前进，也可以一起播放。

## 如何回放

按原轨迹保存的动作顺序恢复场景初始状态，在模拟器上执行动作，并按时间线重现消息、设备离线与恢复等变化；每步采集实际手机画面。回放使用已有决策，不重新调用模型生成动作。

OS-native 使用原工具实现执行 AppFunction、GUI 和监听操作。新执行产生的任务与监听标识会重新对应；AppFunction 可以改变应用状态而不切换前台，因此界面旁同时展示工具返回和状态读回。

当前 OS-native 画面来自完整动作回放。MobileClaw 主要使用原运行保存的动作后截图，打开应用时的一张加载空态已通过原动作回放补录。MobileClaw 的整段新回放尚未通过一致性校验，不将它标成完整重放成功。

任务标签区分原始会话可确认的归属与事件相关上下文。开场消息和用户委托合并呈现，但保留各自时间。所有结果沿用原运行，回放不产生新评分。
